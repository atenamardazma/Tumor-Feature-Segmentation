# Breast Cancer Diagnosis Classification

**Question:** Can measurements of cell nuclei distinguish malignant and benign cases?

**Approach:** Stratified 80/20 train/test split, scaled logistic regression, random forest, classification report, confusion matrices, ROC-AUC and feature importance. The target is remapped so malignant is positive.

**Run:** `jupyter notebook analysis.ipynb`

**Limitations:** Educational benchmark only. No clinical use or external validation.
